# Translations (Arabic / English) & RTL — conventions

Arabic is the default language (`ar`, right-to-left). English (`en`) is the alternative. The viewer
switches language and theme with the toggles in the header / settings; the choice is stored in the
`ca_locale` / `ca_theme` cookies on that device.

## Where strings live

- `src/i18n/en.ts` — source of truth for keys (`export type Dict = typeof en`).
- `src/i18n/ar.ts` — Arabic, typed as `Dict`, so it **must have exactly the same shape** as `en.ts`.
- `src/i18n/server-messages.ts` — Arabic for messages thrown by services / zod validation.
  `runAction()` and `apiRoute()` translate them automatically.

When you need a new string, add the key to **both** `en.ts` and `ar.ts`, in the same section.

## Using translations

Server components / route handlers / server actions:

```ts
import { getI18n } from "@/i18n/server";
const { t, f, fmt, locale } = await getI18n();
```

Client components (`"use client"`):

```ts
import { useI18n } from "@/i18n/client";
const { t, f, fmt, locale } = useI18n();
```

- `t.section.key` — plain string.
- `f(t.section.key, { name, n })` — fills `{placeholders}`.
- `fmt.plural(t.clients.count, n)` — plural objects built with `plural({...})` (Arabic uses zero/one/two/few/many/other).
- `fmt.date(iso)`, `fmt.dateShort(iso)`, `fmt.dateLong(iso)`, `fmt.weekday(iso)`, `fmt.weekdayName(dow, "short")`,
  `fmt.time(instant, tz)`, `fmt.dateTime(instant, tz)`, `fmt.relativeDay(instant, tz)`, `fmt.timeAgo(instant)`,
  `fmt.clock("08:30:00")`, `fmt.greeting(tz)`, `fmt.num(n, digits)`, `fmt.pct(n)`, `fmt.weight(kg, unit)`,
  `fmt.length(cm, unit)`, `fmt.signedWeight(kg, unit)`, `fmt.measure(value, unit)`, `fmt.unit("kg")`.
- Labels for enums: `goalLabel(t, goal)`, `genderLabel(t, g)`, `angleLabel(t, a)`, `measureTypeLabel(t, type)` from
  `@/i18n/labels`; permissions: `t.permissions[key].label / .description`, groups: `t.permissions.groups[group]`.
- Brand: `brandName(locale)` from `@/lib/constants` for text; `<Logo />` / `<LogoWordmark />` for the logo (its aria-label is the brand name in the viewer's language).

Do **not** use the English-only display helpers for UI text: `formatDate*`, `formatTime`, `formatDateTime`,
`formatRelativeDay`, `formatClock`, `timeAgo`, `greetingFor`, `WEEKDAYS*` (lib/time), `formatWeight`, `formatLength`,
`formatSignedWeight` (lib/units), `formatPct`, `plural` (lib/utils), and the English label maps `GOALS`, `GENDERS`,
`PHOTO_ANGLES`, `PERMISSIONS[].label`, `ACTIVITY_LABELS` (lib/constants). Date arithmetic helpers (`addDays`,
`todayInTz`, `diffDays`, `isoDateInTz`, …) and unit conversions (`kgTo`, `toKg`, …) are fine.

Page titles: replace `export const metadata = { title }` with

```ts
export async function generateMetadata() {
  const { t } = await getI18n();
  return { title: t.titles.clients };
}
```

## RTL rules

- Use logical Tailwind utilities: `ms-/me-` (not `ml-/mr-`), `ps-/pe-`, `start-/end-` (not `left-/right-`),
  `text-start/text-end`, `border-s/border-e`, `rounded-s/rounded-e` (`rounded-ss/se/es/ee`), `float-start`.
- `justify-*`, `gap-*`, `space-x-*`, flex and grid already follow the document direction.
- Icons that point somewhere (ChevronLeft/Right, ArrowLeft/Right, LogOut) get `className="rtl-flip"`.
- Emails, phone numbers, URLs, access codes and IDs keep left-to-right: `dir="ltr"` on the element
  (inputs for email / phone / URL / password / codes too).
- Charts: keep Recharts containers `dir="ltr"` (axes stay left→right) and format ticks/tooltips with `fmt`.
- Arabic must never have letter-spacing (handled globally in `globals.css`).
- Numbers use Latin digits in both languages (`ar-EG-u-nu-latn`), which suits gym numbers.
